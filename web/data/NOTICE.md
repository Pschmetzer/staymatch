# Städtedaten

Die JSON-Dateien in diesem Ordner enthalten Orte (Cafés, Haltestellen, Parks usw.) aus OpenStreetMap.

© OpenStreetMap-Mitwirkende, Open Database License (ODbL) 1.0.
https://www.openstreetmap.org/copyright · https://opendatacommons.org/licenses/odbl/1-0/

**Share-Alike:** Die Dateien sind eine abgeleitete Datenbank. Wer sie verändert und weitergibt, muss sie ebenfalls unter ODbL stellen und OpenStreetMap nennen. Der Code des Projekts (MIT) bleibt davon getrennt.

Erzeugt mit `scripts/prefetch-cities.mjs` (Städteliste: `scripts/cities.json`). Das Feld `t` in jeder Datei ist der Abrufzeitpunkt.
